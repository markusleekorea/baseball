# ⚾ 우리집 프로야구

아빠와 아이가 아이패드 하나로 같이 하는 **룰렛 야구 게임**이에요.
타이밍이나 손재주가 필요 없어요. 그래서 다섯 살 아이와 어른이 비슷한 실력으로 겨룰 수 있어요.

## 어떻게 하는 게임인가요?

1. 투수는 자동으로 던져요. 타자 차례가 되면 룰렛이 저절로 돌아가요. 사람은 **타자 역할만** 해요.
2. `🏏 멈춰!`를 누르면 룰렛이 멈추고 **볼 / 스트라이크 / 타격!** 중 하나가 나와요.
3. **타격!**이 나오면 결과가 자동으로 정해져요. 파울, 땅볼, 뜬공, 안타, 2루타, 홈런 같은 결과예요.
   공이 야구장 그림에서 날아가고, 주자들이 베이스를 돌아요.
4. 볼카운트, 아웃, 주자, 점수, 이닝은 진짜 야구 규칙대로 계산돼요. 끝내기, 병살타, 희생플라이, 밀어내기도 있어요.
5. **📣 응원하기**를 누르면 그 타석 동안 타격 칸이 커져요. 룰렛이 도는 중에도 누를 수 있어요.
   - 우리 팀(kt)은 응원을 **무제한**으로 쓸 수 있어요. 다른 팀은 한 경기에 3번이에요.
   - 소리: 메뉴 화면에서는 잔잔한 음악이 나오고, 경기 중에는 관중 소리와 박수 소리가 나요. `⚙️ 설정 → 🎶 배경음`에서 끌 수 있어요.
6. 화면 구성
   - 가운데: 야구장. 수비 9명, 타자, 주자가 이름과 함께 나와요.
   - 왼쪽: 라인업. 타순, 포지션, 오늘 타석 결과가 나오고, 누르면 상대 팀 라인업으로 바뀌어요.
   - 오른쪽: 룰렛과 버튼.
7. 음성 중계: 볼·스트라이크는 짧게 외치고, 안타·아웃·점수는 자세히 중계해요.

- **우리 팀이 더 잘 이기게**
  - config.js에서 kt 선수 능력치(★)를 다른 팀(전부 ★3)보다 높게 해 두었어요.
  - `⚙️ 설정 → 💪 우리 팀 힘내기`의 기본값은 `많이`예요.
  - 3회 경기 기준으로 응원을 안 하면 약 77%, 매 타석 응원하면 약 90%를 이겨요.

- **선수 명단**: KBO 공식 홈페이지 '선수 등록 현황'(2026년 10월 4일 1군 등록 명단)의 이름과 등번호를 넣었어요. 타순과 포지션은 대표적인 주전 라인업으로 골랐어요.

- **룰렛 모드**
  - **공 하나씩**: 볼카운트가 하나하나 올라가요.
  - **타석마다**: 한 번 돌리면 타석 결과가 바로 나와서 빨라요.
- **사람/컴퓨터**: 팀마다 정할 수 있어요. 컴퓨터 대 아이 대결이나 컴퓨터끼리 관전도 돼요.
- **시즌 모드**: 경기가 끝나면 다른 팀 경기도 자동으로 진행돼요. 순위표와 선수 기록(타율, 홈런, 타점 등)이 쌓여요.

## 비밀번호 잠금

- 앱을 열면 숫자 키패드가 먼저 나와요. 비밀번호는 `1015`예요.
- 한 번 맞히면 앱을 완전히 닫기 전까지는 다시 묻지 않아요.
- `config.js`의 `pin: '1015'`에서 바꿀 수 있어요. `pin: ''`로 비우면 잠금이 꺼져요.
- 아이가 혼자 못 열게 하는 정도의 간단한 잠금이에요. 저장소가 공개라서 config.js를 보면 비밀번호를 알 수 있어요.

## 선수 이름, 로고 바꾸기

방법이 두 가지예요.

**① 아이패드 앱 안에서 바꾸기** (`👕 팀·선수 관리`)
- 팀 이름, 선수 이름, 등번호, 포지션, 능력치(★)를 바꿀 수 있어요.
- `📝 이름 한꺼번에 쓰기`로 9명을 한 번에 입력할 수 있어요.
- `📷 로고 사진 넣기`로 아이패드 사진첩의 그림을 로고로 쓸 수 있어요.
- 이렇게 바꾼 내용은 **그 아이패드(그 브라우저)에만 저장**돼요.

**② `config.js` 파일 고치기** (컴퓨터에서 편하게)
- `config.js`를 메모장이나 VS Code로 열어서 선수 이름을 적어요.
- 로고 그림은 `logos` 폴더에 넣고 `logo: 'logos/kt.png'`처럼 적어요.
- GitHub에 다시 올리면 앱을 열 때 "새 설정을 적용할까요?" 하고 물어봐요.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소(repository)를 만들어요. 예: `baseball`
2. **Add file → Upload files**로 이 폴더의 파일을 전부 끌어다 놓고 **Commit** 해요.
   (`.claude` 폴더는 테스트용이라 안 올려도 돼요.)
3. 저장소의 **Settings → Pages**에서 아래처럼 고르고 **Save** 해요.
   - Source: `Deploy from a branch`
   - Branch: `main`, 폴더: `/ (root)`
4. 1~2분 뒤에 `https://<아이디>.github.io/baseball/` 주소로 열려요.

## 아이패드에서 앱처럼 쓰기

1. Safari로 위 주소를 열어요.
2. 공유 버튼을 누르고 **홈 화면에 추가**를 눌러요.
3. 홈 화면 아이콘으로 열면 주소창 없이 전체 화면으로 실행돼요.

- **소리**: 효과음이 안 들리면 무음 모드를 꺼 주세요. 음성 중계는 아이패드에 있는 한국어 음성(유나 등)을 써요.
- **데이터**: 기록은 아이패드 안에 저장돼요. `⚙️ 설정 → 💾 백업 파일 저장`으로 백업할 수 있어요.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 시작 페이지 |
| `config.js` | 팀·선수·로고 설정 (여기를 고치면 돼요) |
| `css/style.css` | 화면 디자인 |
| `js/engine.js` | 야구 규칙과 룰렛 확률 |
| `js/app.js` | 화면과 경기 진행, 음성 중계 문장 |
| `js/wheel.js` | 룰렛 그리기 |
| `js/art.js` | 선수 그림, 팀 배지 |
| `js/audio.js` | 효과음, 음성 |
| `js/data.js` | 저장, 시즌 기록 |
| `logos/` | 로고 그림 넣는 곳 |
